# 캐릭터별 성장 시스템 설계

이 문서는 구현할 성장 시스템의 제안이다. 현재 적용된 이동·카메라·점수 로직과 연결할 지점을 정의하며, 아래 경험치 수치와 캐릭터 예시는 밸런싱 전 초안이다.

## 캐릭터와 스킨

- 캐릭터는 고유 `characterId`, 기본 능력치, 전용 스킬을 가진다.
- 각 캐릭터의 경험치와 레벨은 독립적으로 누적된다. 다른 캐릭터로 바꾸면 그 캐릭터의 기존 진행도를 사용한다.
- 스킨은 해당 캐릭터의 외형이다. 동일 캐릭터의 모든 스킨은 레벨과 해금 스킬을 공유하며 스킨 교체로 경험치가 초기화되지 않는다.
- 게임 시작 시 선택한 캐릭터와 스킨을 한 판 동안 고정한다. 판 도중 변경해서 다른 캐릭터에 경험치를 적립하는 상황을 방지한다.

## 점수와 경험치

점수는 한 판의 성과이고 경험치는 캐릭터의 영구 성장이다. 둘을 분리하면 점수 보너스 아이템 때문에 성장 속도가 과도하게 달라지는 문제를 줄일 수 있다.

- 현재 점수: 처음 도달한 전방 행마다 100점. 뒤로 이동, 좌우 이동, 방문한 행으로 복귀는 0점.
- 추가 점수: 수집기가 골드·아이템별 점수 가치를 계산해 `GameplayController.AddGoldScore(points)` 또는 `AddItemScore(points)`에 전달한다. 중복 수집 방지는 수집기에서 처리한다.
- 경험치 초안: 새 전방 행당 10 XP + 실제 수집한 골드당 1 XP + 목표 달성 보너스 XP.
- 골드 보너스 XP는 판당 100 XP까지, 목표 XP는 정의된 목표를 한 번 완료할 때만 지급한다.
- XP는 최종 점수를 나누어 계산하지 않고, 한 판의 새 전방 행 수·실제 수집 수량·완료 목표를 사용한다.
- 정상 게임 종료 시 선택 캐릭터에게 XP와 획득 골드를 한 번 정산한다. 일시정지는 종료로 간주하지 않는다.
- 결과 저장 실패 시 보상 지급 완료로 표시하지 않는다. `runId`를 저장해 결과 화면 재진입이나 재시도로 같은 보상이 중복 적립되지 않게 한다.
- 강제 종료·앱 종료 시 진행 중 판을 복구할지는 별도 정책으로 정한다. 초기 버전은 완료된 판만 보상한다.

## 레벨과 스킬 해금

초기 최고 레벨은 20. 레벨 L에서 다음 레벨까지 필요한 경험치는 `100 + 50 × (L - 1)`로 제안한다. 레벨 1→2는 100 XP, 2→3은 150 XP이며 남은 경험치는 다음 레벨로 이월한다. 한 번에 여러 레벨을 올릴 수 있다. 최고 레벨 이후에는 누적 XP 기록만 유지한다.

| 레벨 | 해금 제안 |
| --- | --- |
| 1 | 기본 능력치, 캐릭터 기본 패시브 |
| 3 | 능력치 성장 1단계 |
| 5 | 전용 액티브 스킬 |
| 8 | 패시브 강화 |
| 10 | 액티브 강화 또는 전용 변형 |
| 15 | 두 번째 패시브, 능력치 성장 2단계 |
| 20 | 전용 스킬 최종 강화, 숙련 스킨 |

스킬 정의에 해금 레벨·효과·지속시간·재사용 대기시간을 기록한다. 해당 레벨에 도달하면 자동 해금하고 캐릭터 화면에서 확인한다. 별도 구매 재화는 초기 버전에 도입하지 않는다.

## 캐릭터별 능력치 방향

| 예시 캐릭터 | 성장 방향 | 전용 스킬 예시 |
| --- | --- | --- |
| 정찰자 | 위험 예고 범위, 회피 스킬 대기시간 감소 | 앞쪽 위험 구간 미리 표시 |
| 수집가 | 골드 흡수 범위, 아이템 효과 지속시간 | 잠깐 동안 주변 골드 흡수 |
| 수호자 | 보호막 회복 대기시간 감소, 보호막 지속시간 | 위험 충돌 1회 방어 |

능력치는 캐릭터별 기본값에 레벨 보너스를 더해 계산한다. 예를 들어 스킬 대기시간 감소는 레벨당 1%, 최고 15%로 제한한다. 흡수 범위는 해금 단계별로 0.25칸씩 증가시키되 최고 범위를 제한한다. 이동은 계속 한 칸 단위이며 후진 제한도 한 칸을 유지한다.

거리 점수는 모든 캐릭터에게 같은 100점 규칙을 적용한다. 랭킹을 추가할 때는 캐릭터별 랭킹 또는 성장 능력치를 동일하게 보정하는 경쟁 모드를 선택해야 한다.

## 코드와 저장 구조 제안

- `CharacterDefinition` (ScriptableObject): 캐릭터 ID, 이름, 기본 능력치, 레벨 보너스, 스킬 정의, 사용할 수 있는 스킨 ID.
- `CharacterProgress`: 캐릭터 ID, 총 경험치, 선택 스킨 ID. 레벨과 스킬 해금 여부는 경험치와 정의에서 계산해 저장 값 간 불일치를 방지한다.
- `CharacterProgressionManager`: 캐릭터별 진행도 조회, XP 지급, 레벨 계산, 능력치 계산, `LevelChanged` / `SkillUnlocked` 이벤트.
- `RunResult`: 판 ID, 캐릭터 ID, 새 전방 행 수, 거리·골드·아이템 점수, 수집 골드, 획득 XP, 완료 목표.
- `GameplayController`: 현재 한 판의 이동·점수·수집 실적을 집계하고 GameOver에서 `RunResult`를 확정한다. 영구 캐릭터 데이터를 직접 수정하는 역할은 성장 관리자가 맡는다.
- `SaveData`: 캐릭터 진행도 목록, 선택 캐릭터 ID, 최근 정산 판 ID 추가. 기존 버전 1 저장 파일은 마이그레이션해서 유지한다. 기존 골드·업적·음량 데이터를 삭제하지 않는다.
- `SaveManager`: 보상과 정산 판 ID를 한 번에 저장한다. 저장 실패 시 데이터 롤백 또는 정산 대기 상태를 유지해 재시도가 안전하도록 한다.

캐릭터 선택 화면에는 레벨, XP 진행 막대, 다음 해금 스킬, 현재 능력치, 스킨 선택을 표시한다. 결과 화면에는 이번 판 점수 분해, 획득 골드, 캐릭터 XP, 레벨 상승, 새로 해금한 스킬을 표시한다.

## 구현 순서

1. 캐릭터 정의와 스킨 ID 연결, 캐릭터별 XP 저장 및 기존 저장 파일 마이그레이션.
2. 종료 결과 정산과 중복 보상 방지, 캐릭터 선택 화면의 레벨·XP 표시.
3. 레벨별 능력치 계산과 스킬 자동 해금 이벤트.
4. 실제 골드·아이템 수집, 전용 스킬 효과, 결과 화면.

현재는 이동·점수 집계까지만 구현되어 있다. 성장, 수집, 결과 정산, 스킬 효과와 저장 마이그레이션은 이 설계를 바탕으로 다음 구현 단계에서 추가한다.
